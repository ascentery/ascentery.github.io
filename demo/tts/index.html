How voice selection works. On load the page requests your browser's available voices and picks the best female English voice using this priority order: Microsoft Jenny → Microsoft Zira → any Microsoft female en-US → any female en-US → any en-US → browser default. You can also pick any voice manually from the dropdown above. All synthesis happens on-device via the Web Speech API — nothing leaves your browser.
