How this works. Uses text2wav — eSpeak-NG compiled to WebAssembly via Emscripten. The synthesiser generates a WAV file entirely in-browser (no network calls after first load), which this page decodes with the Web Audio API. First visit downloads ~2 MB of WASM + voice data; cached on subsequent visits. Synthesis latency is typically 10–50 ms.
